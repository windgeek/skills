Agent Skills are folders of instructions, references and scripts that an AI agent loads when a task calls for them. Every skill here came out of real, repeated work: each rule is there because something went wrong without it. They follow the open `SKILL.md` format, so they work with Claude Code, Codex and any other agent that can read skills; nothing is tied to one vendor.

## Quick start

Tell your agent:

> Install the **plain-reply** skill from https://github.com/windgeek/skills for me.

Then just describe what you want ("reply to this message for me", "narrate this script in my voice"). The agent picks the right skill, explains anything it needs to download, and asks before doing it.

<details>
<summary>Manual install</summary>

Copy a folder from `skills/` into your agent's skills directory, for example `~/.claude/skills/` for Claude Code or `~/.agents/skills/` for agents that read the shared location. Claude Code users can also add this repo as a plugin marketplace (`.claude-plugin/marketplace.json`).
</details>

## chinese-human-editor

Finished Chinese drafts often read as machine-written: "not X but Y", symmetrical aphorisms, triple parallels, "underlying logic", an ending that suddenly turns to the times. After drafting and before publishing, this skill has the agent make one separate pass as an editor: a script flags candidates (narration and dialogue counted apart), each is judged in context, and a second script compares numbers, quotes, titles, links and names before and after, so de-AI editing never quietly changes facts. Strength adapts to articles, literary fiction and web serials.

Used by `wechat-article` and `novel`.

Requires: Python 3.

## douyin-interest-card

Douyin "interest cards" are lightweight interactive cards distributed by interest, generated from a text description in Douyin Creator Center's AI Workshop. This skill has the agent turn one of your topics into a card: design the interaction (one complete mini-game on the card, a deeper landing page), write the copy and the AI Workshop prompt, check it against the platform rules, generate it, test every branch in the preview, iterate on fixes, and fill in the publish settings. It asks you before clicking publish.

- `render_states.py`: Renders a tagged SVG into one transparent PNG per interaction state, since the card runtime does not display SVG.

Requires: a Douyin Creator Center account and an agent that can drive your logged-in browser; the image script needs Python 3 and Google Chrome.

## novel

Long serials break down after a few dozen chapters: characters know things they shouldn't, promised meetings never happen, place names drift, foreshadowing is never paid off. This skill has the agent run the novel as a project: setting, outlines, characters, a continuity log and a foreshadowing tracker live in `novel/`, loaded in tiers before each chapter and checked and updated after it. Then you just say "continue": it restores state, decides whether a consistency check or a new outline is due, and writes the next chapter.

- Chapter length, title and formatting rules follow Fanqie Novel's limits; adjust them for other platforms.
- Proven on a real serial of over a million characters: a consistency audit every 10 chapters and per-volume archiving keep the per-chapter context small even after hundreds of chapters.

Requires: an agent that can read and write local files.

## plain-reply

After the debugging, the reconciliation or the analysis, the last step is usually "reply to someone". Models default to a report: bold headings, numbered lists, "in conclusion", which turns into asterisks in a chat app and nobody reads. This skill has the agent write a message you can paste and send: the conclusion in the first line, one short block per person or item, names, times, amounts and evidence included, conversational and never absolute; insider and outsider wording kept apart, attachments for outsiders de-identified first. When you edit its draft, it turns your edits into rules and writes that way next time.

- Works for WeChat, Lark, DingTalk, Slack, group chats and short emails; replies in your language.
- Ships before/after examples (report voice → plain words, long draft → trimmed, a correction).

Requires: any agent; works best with one that keeps preferences across sessions (memory or a project instructions file).

## wechat-article

Writes WeChat Official Account articles people finish: a topic card first (reader, tension, claim, payoff, evidence), primary sources for every load-bearing claim, cutting at structure / paragraph / sentence level, and ten pre-publish gates; popular-science pieces get a puzzle → mechanism → transfer method. Outputs two Markdown masters.

- Layout is handed to `wechat-typeset` from this repo.
- Uploading to the drafts box is optional, needs your own AppID/AppSecret in `.env`, and only runs when you explicitly ask.

Requires: Python 3.

## wechat-typeset

Typesets a Markdown article for the WeChat Official Account editor in one quiet "book page" style: serif body text, centred chapter headings, generous whitespace, and a single accent colour (vermilion by default, adjustable to suit the article) used only for section numbers, list markers, footnote numbers and a small end mark. No cards, icons or gradients. A script does the layout deterministically, so the source text is never rewritten.

- Links become footnote numbers with URLs listed after the body, since in-body links don't work in WeChat.
- Includes a compliance checker and a phone-width preview with a dark-mode toggle and a one-click copy button.

Requires: Python 3.

## code-cinema

Makes artistic music videos and short films in code, without video-generation models.

**It evolves.** For every film it analyses the song, then invents a fitting visual style ("the medium is the content") and saves it to a growing style library. Existing styles are reused only when they truly fit, and two films in a row never share a style. The 4 bundled styles are just a starting point.

**Automatic pre-delivery check.** `framecheck.mjs` flags cuts whose visual change misses the beat, stray flicker frames, overlapping or clipped text, long static stretches and non-deterministic frames, and outputs a contact sheet with the problem areas boxed in red.

Requires: Apple-silicon macOS, Chrome, ffmpeg, Node.js, Python 3.

## suno-music-producer

Writes songs for Suno, growing a full song from one line, groove or scene, and outputs ready-to-paste Title, Styles, parameters and Lyrics; Chinese lyrics are checked line by line for stress, tone inversion and breathing.

Requires: a Suno account.

## voice-clone

Clones your own voice locally (Apple Silicon Mac, CosyVoice3). Everything runs on your machine; no audio is uploaded.

- Nothing is bundled; ~10 GB is downloaded on first use, after your consent.
- After generation, an offline listen-back check (macOS 26 speech recognition) compares each line with the script by pinyin and flags likely misreadings or dropped words for you to re-listen.
- Only clone your own voice, or one you have explicit permission to use, and label published audio as AI-generated.

## apple-app-localization

Internationalizes and translates Apple-platform apps: migrates legacy `.strings` to String Catalogs, adds plurals, and uses generated symbols so a misspelt key fails to compile. OS terms are looked up from macOS's own resources, never guessed; drafting and review are separate passes, followed by runtime checks per locale. Later feature work that adds strings gets every language filled in too.

Requires: macOS, Xcode 26+, Python 3.

## ship-macos-apps

When an AI coding agent helps build a macOS app, the usual failures are about identity: Debug and Release share a bundle ID, or the agent launches the production build from a shell, and permissions or the menu bar icon break on the developer's Mac only. This skill keeps development, local Release, TestFlight and App Store as four separate lanes, with read-only project / installed-app audits, release gates, and small scripts to set or increment the version and build number, check that an archive shows the build it contains, and archive and upload without opening Xcode (the upload prints a summary and waits for confirmation; iOS and Mac Catalyst too). It also covers store screenshot posters, filling App Store Connect pages and uploading screenshots per locale, and iPhone Duo (foldable) support.

Requires: macOS, Xcode.

## knowledge-placement

If you use several agents, each one keeps its own "memory". Claude Code's auto-memory lives under `~/.claude/projects/<project>/memory/` and only Claude reads it: a rule saved there does not exist for Codex. Memories are also keyed by project path, so moving or renaming a project silently orphans them. This skill has the agent write each piece of knowledge once, where every agent can read it: one global conventions file (other agents' global files symlinked to it), one shared skills directory, the project's `AGENTS.md` (with `CLAUDE.md` / `GEMINI.md` as symlinks), and project docs for long material. Private memory holds only what is specific to that agent, and is usually empty. It also covers a periodic audit: back up, inventory, move or delete each memory, and report.

- `inventory.py` (read-only): lists each Claude Code memory directory, the project it maps to (flags ones that no longer exist), which instruction files the project has, and every memory entry with type and size.

Requires: Python 3 (for the script).

## project-cleanup

Projects are usually small; the space goes to the toolchain caches behind them. This skill has the agent inventory both, delete what is regenerable or superseded, keep what gets reused (simulators, symbols of shipped builds, inputs of the current pipeline), check references before deleting, confirm the list with you, and report what was freed.

- `scan.py` (read-only): lists the largest entries, files outside git, stray files, detected global caches and free space.

Requires: Python 3, macOS or Linux.

## skill-refine

Skills grow by appending lessons, and soon the same rule appears three times, new rules contradict old ones, and the hard rules get buried. After every skill edit, this skill has the agent read everything, file the new rule under the right topic, merge duplicates, resolve contradictions in favour of your latest intent, keep SKILL.md lean, never water down a requirement, and report what changed.

- `lint_skill.py` (read-only): checks structure, duplicates across files and skills, contradiction hints, and append-only sprawl.
- `remind_hook.py` (optional): a Claude Code hook that reminds the agent once per skill per session; installed only with your consent.

Requires: Python 3.

## zlib-books

This skill lets the agent find books through the zlib CLI: search, shortlist up to five editions (single volumes first, high rating and quality, real publishers, sane file size, epub preferred), download only the one you pick, and email it to your Kindle with a bundled script. Daily quota is limited, so it never downloads speculatively. Use it only for books you have the right to obtain; you log in and set the mail authorization code yourself.

- `send_kindle.py`: Sends a file to your Kindle address using the settings from `zlib kindle config` and `ZLIB_SMTP_PWD`, with an ASCII-safe attachment name.

Requires: Python 3, the zlib CLI with your own account, a mailbox SMTP authorization code, and the sender added to Amazon's approved senders.
