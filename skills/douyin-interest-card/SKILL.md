# 抖音兴趣卡

兴趣卡是抖音按兴趣分发的轻量互动卡片，在 **AI工坊** 里用文字描述生成（背后是一个会写代码的 agent，卡片跑在 Lynx 环境里）。一张卡 = **卡片首屏**（在卡内完成一个完整的小玩法）+ **落地页**（点行动点后进入，接着往深里讲）。

- 入口：`https://creator.douyin.com/creator-micro/ai-application`，输入框下方选“兴趣卡”模式
- 创作规范：`https://creator.douyin.com/creator-micro/ai-application/interest-card-guide`，要点摘在 [references/spec.md](references/spec.md)
- 在 AI工坊 里的操作和踩过的坑：[references/aigongfang.md](references/aigongfang.md)

## 流程

1. **定玩法**（先和用户确认）
   - 一张卡只讲一个主题，从用户已有内容里挑**观众能凭直觉回答、答案又会分歧**的问题。思想实验、两难选择最合适。
   - 卡片首屏：一个有物理感的操作（滑块、拖动、抽签），加一个确认按钮，然后在卡内给出结果。核心操作不超过 3 步，核心功能不超过 2 个。
   - 结果按选择分 2–4 类，每类说清“你看重的是什么”，再留一个钩子把人引向落地页。
   - 落地页：开头显示卡片里的答案（保持状态）→ 往下推一层的问题 → 最后一问联系到观众自己 → 指向完整内容（比如视频）。
2. **写文案**：在项目里建 `<卡名>.md`，结构：基本信息表（标题 ≤10 字、行动点 ≤6 字、分类）→ 卡片首屏 → 结果 → 落地页 → 给 AI工坊 的描述（一整段，可直接粘贴）→ 提交前自查 → 事实核查。文案标准跟着所属项目走；去 AI 腔可以用 chinese-human-editor 的 `scan.py`（如果装了）。
3. **画面先自己做好**：卡里的核心图（随交互变化的那张）不要交给 AI工坊 画，它画出来常常是方块拼凑，看不出是什么（实测让它画一艘十块木板的船，得到的是一根桅杆加一排方格）。做法是自己先画一个 SVG，用 `scripts/render_states.py` 渲染成每个状态一张的透明 PNG，上传给 AI工坊，让它按状态切换图片。AI工坊 的卡片环境显示不了 SVG，不要直接给它 SVG。
4. **在 AI工坊 生成**：粘贴描述 → 发送 → 等它跑完（一般 10–20 分钟）→ 预览**亲手把每个分支点一遍** → 列出问题，一轮发过去改（“文字一个字都不要改”要写明）→ 再验。操作细节见 aigongfang.md。
5. **发布**：点“去发布”，填名称（≤10 字，和卡片标题一致）、介绍、图标，打开场景（侧边栏 / Feed / 搜索）。**点“确认发布”前先问用户**；用户同意后再点。提交后在“发布结果”里能看到“审核中”。
6. **收尾**：在卡片的 md 末尾记一节“制作记录”：项目名、版本、改过几轮各改了什么、发布配置、审核状态。审核结果出来后补上。

## 注意

- 平台不支持：金融、医疗、通信、教育、法律等需要资质的方向，以及纯消费转化。知识类内容选“人文艺术 / 知识文化 / 趣味测试”，别选“教育”。
- 卡内和落地页**不放站外链接**（B 站等）。能链到自己的抖音视频或主页就链，不行就写一句“完整讲解在《……》第 N 期”。
- 右上角的“AI生成”角标是 AI工坊 的外壳自带的，保留。
- 结果里的“有 xx% 的人和你选得一样”是真统计，预览测试时点的票也会算进去，发布后看一眼。
- AI工坊 生成后会自己加背景音乐、改名称、写介绍，这些都要检查，不合项目约定就改掉。
