# 抖音兴趣卡创作规范（摘要）

来源：抖音创作者中心“抖音兴趣卡创作规范”页（2026-10-19 读取）。提交前逐条核对。

## 硬指标

| 项 | 要求 |
|---|---|
| 标题 | ≤10 字，完整显示，直接说明核心玩法；不用宽泛名称、黑话，不能和实际玩法对不上 |
| 行动点文案 | ≤6 字符，写清下一步（“立即查看”“继续答题”“观看更多”），点击必须真的有效 |
| 图标 | 200×200 px，png / bmp / jpeg / jpg / gif，无水印，在头像框里完整可辨 |
| 加载 | ≤3 s 加载完；不能有空白、缺素材、裂图、加载后变糊 |
| 交互反馈 | ≤200 ms |

## 内容

- 一个核心主题，表达轻量好懂；不放冗余信息、营销广告、诱导交易、第三方引流。
- 合法、健康、不夸大；没有授权不能用受版权保护的内容。
- 方向：从真实兴趣点切入、做自己擅长且能长期输出的；不支持非用户兴趣、纯消费转化，以及金融、医疗、通信、教育、法律等高风险或需资质的方向。

## 交互

- 至少 1 个有意义的互动区域（答题、抽签、滑动等）；长按不能作为主要功能；卡内不能登录授权。
- 核心功能 ≤2 个，放在首屏明显位置，非核心功能不能打断主流程。
- 核心操作 ≤3 步，卡内走完一个完整玩法，并给出明确结果。

## 设计

- 字体统一，信息分层；没有字号失衡、乱码、堆叠、截断，元素间距合理。
- 内容层有清晰的圆角边框，核心信息和按钮不能溢出内容区。
- 遮罩层用背景图延展出的纯色，覆盖自定义区域和主按钮，突出内容层。
- 背景克制：不用强渐变、高饱和撞色、复杂纹理、过强光效；图片不糊、不乱裁、无水印。

## 落地页

- 内容和卡片相关，保留卡片里的互动状态，视觉风格一致。
- 核心功能清楚，不混进无关功能。卡片主按钮默认进入落地页首页；主按钮不用“继续”这类接续性文案。

## 结构

五大要素：标题、图标、内容、交互、行动点。三个图层：背景层、算色遮罩层、自定义内容层。
