# 在 AI工坊 里操作（2026-10 实测）

用能操作用户本人浏览器的工具（用户已在其中登录抖音创作者中心）。没有登录态的浏览器打开只会看到登录页。以下操作名（点击、拖动、读取元素、上传文件）对应你所用浏览器工具里的同类功能。

## 输入描述

- 输入框是 tiptap / ProseMirror 编辑器（`.tiptap.ProseMirror`）。普通的“填表单”填不进去；直接模拟键盘输入的话，换行会触发发送。
- 可行的做法：用 JS 派发一次粘贴事件：
  ```js
  const ed=document.querySelector('.tiptap.ProseMirror'); ed.focus();
  const dt=new DataTransfer(); dt.setData('text/plain', txt);
  ed.dispatchEvent(new ClipboardEvent('paste',{clipboardData:dt,bubbles:true,cancelable:true}));
  ```
  粘完稍等一下再读 `ed.innerText.length`，核对长度和末尾几个字，确认整段都进去了。
- 确认输入框下方选的是“兴趣卡”模式。**不要点“优化指令”**，它会改写你的文案。
- 发送按钮在输入框右下角；运行时同一个位置变成“停止”。

## 上传图片

- 页面上有隐藏的 `input[type=file]`（class `creator-aihub-upload-hidden-input`，支持多选）。定位到这个元素，用浏览器工具的上传文件功能传本地路径，一次可以传多张；不要点按钮打开系统文件选择框。
- 传完缩略图会出现在输入框上方，和下一条消息一起发出去。
- 实测传 11 张时它只认到 9 张，剩下两张按同样规格自己补画了。发完要在预览里核对每个状态的图是不是你给的。

## 等待和卡住

- 第一次生成大约 15–20 分钟：写设计文档 → 生成背景图和配乐 → 写服务端和卡片、落地页 → 装依赖 → 启动 dev 服务 → 自检。之后每轮修改 5–10 分钟。
- 等待时分批轮询（每批一两分钟），单次等太久浏览器工具可能超时。
- 进度看左下角的“任务清单 N/M”和“正在处理 Xm”。
- 实测卡住过一次：预览早就能用了，它还在“等待 dev 服务启动完成”上空等了近 10 分钟。遇到这种情况，点停止，然后直接把修改要求发过去，不会丢东西。

## 预览实测

- 右侧有“兴趣卡”“兴趣卡落地页”两个标签。手机框里可以真的拖滑块、点按钮。
- 从卡片点行动点，预览会跳到落地页，并且带着卡片里的答案。可以用这个检查“状态连续”。
- 每个分支都要点到：每类结果、落地页的每组选项、结尾。文字逐字和 md 对照。
- 顶部 ⓘ 是“检查清单”（平台自动检查），可以看一眼，但它只查技术问题，不查画面和文字。

## 它常犯的错（第一版里都出现过）

- 标题自作主张，换成了一个泛泛的名字。
- 让它画一艘船，结果只有一根小桅杆加一排方格，中间大片空白 → 自己画图上传（见 SKILL.md 第 3 步）。
- 给它 SVG，它照用了，但卡片环境不显示 → 改用 PNG。
- 结果页卡片内部又放了一个行动点按钮，和下方的行动点重复。
- 落地页没有接上卡片里的答案。
- 自动加了背景音乐。
- 发布配置里名称写成“××互动问答”，介绍有 AI 腔。

## 发布配置

- “去发布”打开的面板里有：代码版本、兴趣卡名称、图标、介绍、场景开关（抖音侧边栏 / 抖音 Feed / 抖音搜索）。会自动保存。
- 名称和介绍是受控输入框，直接改值会被弹回去。要先点进框里，全选（macOS 上 `cmd+a`），再模拟键盘输入，然后点空白处让它失焦。
- “确认发布”需要用户先同意。提交后提示“提交成功”，“发布结果”里显示版本号和“审核中”，右侧有“撤回”。
- 审核通过后：自己在抖音左上角 ☰ → 小程序里看；Feed 和搜索要看平台推不推。
