# 去 AI 腔终审

把“像模型生成的稿子”改成一个具体的人在具体处境里写出的文字。不是改口语，也不是故意写糙：让信息、判断和节奏都有来处。

**为什么要单独一遍。** 边写边审，会放过自己刚写的句子。终审要在稿子写完、事实核实之后，换成编辑的身份从头读，只做这一件事。稿子还缺证据、结构或主张时，先回写作流程补，不用修辞盖住内容的窟窿。

## 不可改动

- 事实状态、人物立场、数字、日期、专名、引文、链接、必要的免责声明和限定语（“可能”“通常”“截至某日”）。
- 不把推断改成事实，不补写作者没给的亲历、对话、场景或情绪。
- 不为了“像人”加错别字、网络黑话、冒犯性表达或无关的个人意见。
- 不把作者原有的锋芒、幽默和不规则的节奏磨成中性新闻稿。

## 流程

1. **留原稿。** 改之前复制一份：`cp 稿.md 稿.orig.md`（项目在 git 里也可以直接用上一个提交）。
2. **扫描：**
   ```bash
   python3 <本skill目录>/scripts/scan.py 稿.md [--genre article|fiction|webnovel]
   ```
   它按下面的病症列出线索，叙述和对话分开计数。线索不等于必须删：逐条回到上下文判断。
3. **通读并修改。** 先逐节写出这一节唯一不可删的事实或判断，再按病症清单改。直接改母稿，不另出“修改版”。
4. **核对漂移：**
   ```bash
   python3 <本skill目录>/scripts/drift.py 稿.orig.md 稿.md
   ```
   数字、引号里的话、书名号、链接、英文专名，只要前后不一致都会列出来。每一条都要能说清楚为什么变；说不清就改回去。
5. **交付。** 默认只交最终稿和一句说明。用户要看修改痕迹时，再列最重要的 3–6 处和理由。

## 按体裁调强度

| 体裁 | 怎么改 |
|---|---|
| 公众号、评论、文案（`article`） | 全部病症都改；标题单独过一遍 |
| 文学小说（`fiction`） | 叙述里的禁用句式必须为零，对话里逐条判断是不是人物口吻；语域、比喻、连续性属于写作手艺，不在本 skill 范围 |
| 网文（`webnovel`） | 保留爽感节奏：章末钩子、对白、反转处的单句段不算短句表演；重点清解释情绪、假金句、流程套话和万能升华；不要改成文学腔 |

## 病症清单

### 句子

1. **假转折。** 叙述里出现这些句式，默认改写：
   - 不是 A，而是 B / 不是 A，是 B（没有“而”字的变体最容易漏）
   - 这不是 A，这是 B / 这不只是 A，更是 B
   - 真正的 A，不是 B / 与其说 A，不如说 B
   - 其实…… / 换句话说…… / 意味着…… 连续充当转折
   - 那一刻我明白了…… / 后来我才知道……（后者全文最多一次）

   有真实的转折，就写成具体的因果或条件；没有就删。
2. **解释情绪。** 叙述者停下来告诉读者某种感受是怎么回事（“最折磨人的地方在于……”）。只摆事实和动作，让读者自己得出。
3. **情绪词直陈。** “痛苦、愤怒、尴尬、绝望、崩溃、五味杂陈”换成身体反应、动作或视线落点。小说必改，评论文章酌情。
4. **假金句。** 对称、响亮，却不增加事实或判断的句子。泛称主语（“一个人……”“人在……的时候”）和全称判断（“往往”“从来都”）都算。每节最多留一句，而且要别扭、不对仗；删掉后信息不受损的，就该删。
5. **整齐排比。** 三个同句式并列、三个并列例子、正反合。最多留两项，或打破整齐；人物慌乱时的重复例外。
6. **抽象词堆叠。** “本质、核心、底层逻辑、维度、颗粒度、叙事、时代、价值、赋能、闭环、抓手”附近没有具体对象或动作。补回对象，或拆掉包装。
7. **流程套话。** “首先、其次、最后”“一方面、另一方面”“值得注意的是”“不得不说”“众所周知”“让我们一起”，以及读起来像主持词、课程提纲、工作汇报的句子。删掉，用内容自身的顺序推进。没有来源的热度词（“刷屏了”“圈内炸了”“所有人都在讨论”）要么给出来源，要么删。

### 段落

8. **短句表演。** 把一个完整意思劈成多行单句来显得有力。连续三段以上的短叙述段逐一确认：是刻意的顿挫，还是偷懒；同一动作链、同一判断合并成自然段。
9. **概括代替细节。** “编了三十个理由”“想了很多”。摊开写其中一两个，或删掉；假精确的数字（拿数量顶替内容）同理。
10. **模板节奏。** 相邻段落长度相同、都以总结句收尾；每节都按“金句开头—三点解释—金句总结”运行；每段加粗一句；破折号过量。打乱它：允许一个朴素的句子跟在漂亮句子后面，强调只留真正承重的地方。

### 结尾与标题

11. **万能升华。** 结尾突然谈时代、人性、命运、未来，“我们每个人”“未来值得期待”“选择适合自己的”“背后是一场……”“时代已经改变”。回到开头那个具体对象，给出有限的判断、现实的代价，或仍然未知的地方。
12. **套路标题。** 下面这些骨架默认重写，除非作者刻意为之且全文只此一处：
    - 最狠的不是 A，而是 B / 真正的 A，不是 B，而是 C
    - A 变天了 / A 要完了 / 所有人都低估了 A / A 的尽头是 B / 这届 A 正在偷偷 B
    - 看完沉默了 / 我发现一个秘密 / 终于有人说清楚了 / 炸裂、封神、杀疯了
    - 冒号前后把同一个结论说两遍

    先回答“发生了什么变化或冲突”，再从正文里找一个能兑现的说法。允许平实，不伪造悬念。

## 恢复人的声音

- 判断带上边界：在什么条件下成立，还有什么不知道。
- 语气由材料里已有的细节撑着，不制造细节。
- 幽默来自人物、处境或事实的错位，不靠括号吐槽和梗。
- 能直说的地方直说，不把每个观点包装成宣言。

## 完成检查

- 扫描线索都已逐条判断过；叙述里的禁用句式为零（对话里的已确认是人物口吻）。
- `drift.py` 列出的每一处变化都说得清理由。
- 随机抽三段相隔很远的文字遮住上下文读：听得出具体题材、作者立场和不同的呼吸节奏。
- 标题（如果有）不在套路骨架里，并且正文兑现了同一件事。
