# Voice Clone（本地声音复刻配音）

用用户自己录的 10–20 秒样本，在本机生成任意台词的配音。声音是一个频道最强的辨识度：用户本人的声音独一无二、可长期使用、没有版权问题，所以优先复刻本人，不要复刻名人或他人的声音（《民法典》保护声音权，平台也会查）。

路径约定：`$VOICE_CLONE_HOME`（默认 `~/voice-clone`）下有 `CosyVoice/`（代码）、`models/Fun-CosyVoice3-0.5B/`、`voices/<名字>/`（每个音色一个目录）。Python 环境是 conda 环境 `cosyvoice`，解释器 `~/miniconda3/envs/cosyvoice/bin/python`（下文记作 `$PY`）。脚本都在本 skill 的 `scripts/` 下。

## 工作流

1. **看现状**：`ls $VOICE_CLONE_HOME/voices/` 和环境是否存在。已装好就跳到第 4 步；已有用户音色（常见名字 `me`）就直接生成。
2. **安装**（仅首次）：先告诉用户要下载什么、多大（代码很小，模型约 7.4 GB 来自 ModelScope，依赖约 2–3 GB 来自 PyPI，装在独立 conda 环境），**得到明确同意后**再运行 `bash scripts/setup.sh`。耗时较长，放后台跑。出错看 [references/troubleshooting.md](references/troubleshooting.md)，里面记录了在 Apple 芯片上真实踩过的坑。
3. **录样本**：把 [references/recording.md](references/recording.md) 里的录音指导转述给用户（设备、环境、语气、朗读稿）。用户导出后：
   - 语音备忘录的临时文件路径受 macOS 保护读不到，请用户把录音**拖到项目目录**里。
   - 请用户把 iPhone“转写”的文字发来，再逐字对照朗读稿，**把不一致处问清楚**。样本文本和音频一字不差，复刻才准。
   - 体检并登记：`python3 scripts/prep_sample.py <录音> --name me --text "逐字文本"`。把体检表转述给用户；❌ 项（破音、太短、太吵）建议重录，⚠️ 项说明影响即可。
4. **先试音，再量产**：用 2–3 句有代表性的台词生成试音（`--takes 2` 或对比 `--llm base`），请用户听“像不像、自然不自然、有没有错字、节奏”。你听不到声音，**音色好坏只能由用户判断**，不要自己宣称“效果很好”。
5. **生成**（`$PY scripts/clone_tts.py ...`，用法见脚本头部注释）：
   - 整份脚本用 `--segments script.json --out build/voice/`。默认**按句**生成：只在句末 。！？ 切句（句中的停顿标记 ｜ 不切开，整句一次生成，语调和气息才连贯；｜ 的位置记在 manifest 的 `beats` 里，由下游拉长停顿），每句一个 wav，另外写一份 manifest.json 记录每句的字幕文字和结尾类型；句间留白交给下游（例如你自己的视频合成脚本）决定。只有旧流程才用 `--no-split` 整段生成。零散句子用 `--text` 或 `--lines`。
   - 有 `voiceText`（带拼音纠音等标记）时，它和 `text` 的切句数量必须一致，也就是两者的 。！？｜ 位置要相同。
   - 很短的片段（比如“没有。”）也能正常生成，但请用户重点听一下这些地方的语气。
   - 默认 `--llm rl --device mps`：RL 版错字更少，用户试听也更喜欢；MPS 比 CPU 快约 20%。
   - 耗时大约是音频时长的 2.5–3 倍（3 分钟台词 ≈ 9 分钟），整期要放后台跑。
   - 看输出里的“字/s”：⚠️ 表示语速异常，往往是吞字或卡住，重生成那一句。
6. **精修**：只重做有问题的段或句（`--only s3,s7`；`--only s16:2` 只重配一句），需要挑版本时加 `--takes 3`。**种子是固定的，同一文本重配结果不变**：念坏的句子要改措辞或换 take，原样重跑没用。控制手段见 [references/text-control.md](references/text-control.md)，包括多音字拼音、`[breath]`、语气指令、语速。
7. **后期与交付**：人声链（去嗡声、轻压缩、提温暖和清晰度）的 ffmpeg 参数见 text-control.md 末尾。交付给用户试听时，统一响度到 -16 LUFS 左右。
8. **合规提醒**：凡是要发布的内容，提醒用户在平台打开“AI 生成内容”声明。依据是《人工智能生成合成内容标识办法》（2025 年 9 月起施行）；B 站在投稿页的“创作声明”，抖音在“高级设置 → 作者声明”。

## 给用户的沟通要点
- 你只能从时长、响度、频谱这些数据判断，听不见声音好坏；请用户听完再下结论。
- 失败时如实说明原因和下一步，比如网络抖动就重跑，缺依赖就补装。不要跳过报错往下走。
- 下载大文件、接受第三方条款（例如 Anaconda 频道的服务条款）都要用户本人确认，不要替用户做决定。
