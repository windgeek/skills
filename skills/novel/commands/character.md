# character 命令详细规则

> 从 SKILL.md 拆出。仅在 `/novel character` 系列命令触发时加载。

## 角色创建必填字段

参考 [templates/character_template.yaml](../templates/character_template.yaml)：

- 基本信息（姓名、年龄、外貌特征）
- 性格内核（三个核心形容词 + 具体表现）
- 说话风格（口头禅、语气特点、示例对话 3 段）
- 核心动机（想要什么 + 为什么想要）
- 内在矛盾（内心冲突）
- 能力/实力定位
- 角色弧线（开始→转折→结局的变化）
- 与其他角色的关系

## character_state.md 入选规则

避免次要角色污染状态文件：

- **主要角色**（命名+yaml）：必入
- **活跃配角**：满足任一条件即入 — ① 累计出场 ≥2 章；② 对当前剧情有推动力（即便只出场 1 章但留下未闭合线索/伏笔）；③ 与主角有持续关系（家人、同事、合作者等）
- **一次性龙套**：仅在该章 log "出场角色"或"被提及角色"中标注，不入 character_state.md
- **升级触发**：原本是龙套的角色再次出场 → 立即升级为活跃配角并补建 state 块（连同首次出场章节的回填）

## character_state.md 顶部硬属性速查表

防代词/称谓错乱核心机制：

- 维护一张全角色硬属性表：性别/年龄/代词/称谓惯例/首次出场章
- 每次新角色入 state 时必须同步更新此表
- 写章前 Tier 1 加载只读此表（30-50 行），避免拉全角色详情
