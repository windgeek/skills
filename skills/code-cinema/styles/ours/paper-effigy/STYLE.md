# 纸扎夜游 · Paper Effigy Night Ride — Style Prompt

> 整个世界是纸扎店里扎出来的：纸人、纸扎的交通工具、纸灯笼、纸糊的店面和招牌，全都是竹篾骨架上糊的彩纸，在午夜的城市里被红灯笼和便利店的冷光照着。人物像木偶一样僵硬地动，脸上是画出来的两团腮红和一个不会变的微笑。转场靠烧纸：纸边发红、卷曲、变成灰，露出下一个场景。
> 参照（只学语法）：中国民间纸扎工艺（竹篾骨架、彩纸、画脸、金箔）；纸扎现代化的真实现象（纸扎手机、纸扎汽车、冥币）；定格动画和纸偶剧场的布景感；民俗恐怖片的“安静的诡异”。不照搬任何作品的角色、场景和镜头。

## 1. 它是什么，它不是什么

- **一切都是纸**：没有“真实”的东西。现代物件（手机、家电、招牌）也是纸扎的，这就是荒诞的来源。
- **纸人的脸**：粉白的纸面，两团正圆的腮红，墨画的细眉和眼，一点红唇，表情永远不变。诡异感来自“不变”，不是来自恐怖的样子。
- **背光的纸**：灯笼、便利店招牌、手机屏幕的光从纸后面透出来，照出里面的竹篾骨架。
- **布景感**：像纸扎店里的一个橱窗，几层纸片前后排开，有景深和视差。

它**不是**过年的红色窗花剪纸（喜庆），不是皮影（虽然影子会被借用一次），不是 Q 版可爱纸片人，也不是血腥的恐怖片。**“恐怖不是青面獠牙”**：不出现鬼脸、血、跳吓。

## 2. 材质与渲染（Canvas 2D 为主，WebGL 做烧纸和光）

- **纸面**：每块纸是一个平面形状 + 纸纤维噪声（低对比的 fbm）+ 一两道折痕（亮暗各一条细线）+ 边缘略微不齐（路径加小幅抖动，用固定种子）。
- **糊纸的层次**：同一个物体由几块不同颜色的纸拼成，拼缝处有一条细细的浆糊亮边或者重叠的阴影。
- **竹篾骨架**：背光时显出来（深色细线组成的网格和弧），平时藏在纸后面。
- **画脸**：腮红是两个半透明的正圆，边缘略晕；眉眼是墨线，线头有提笔的尖；红唇一点。上色有轻微错位（套色不准），像手画的。
- **金箔与亮片**：纸扎常见的装饰，小面积，随光闪。
- **光**：红灯笼（暖红，柔和，下半部更亮）、便利店日光灯（冷绿白）、手机屏幕（冷蓝白）。每个光源用径向渐变 + 纸的透光（光在纸后时，纸变亮并显出骨架）。
- **烧纸**：WebGL 着色器做。噪声阈值随时间推进，阈值线上是一圈橙红的火边（HDR，参与辉光），火边外侧变黑卷曲，内侧露出下一个画面；灰烬是飘起的小黑片和少量火星。
- **镜头**：2.5D 布景，前景、主体、背景三到五层纸片，推拉时有视差；远景层轻微模糊。

## 3. 色彩逻辑

- 底色是**午夜的蓝黑**。纸扎自己的颜色是俗艳的：**品红、翠绿、明黄、金、粉白**，这种“冥器配色”本身就有一点瘆人。
- 两种光的对抗：**灯笼红**（民俗、祭祀）和**便利店冷白绿**（现代、城市）。一个镜头以一种光为主，交界处是看点。
- **黄纸符**的黄（#E3C04A 附近）+ 朱砂红字，是全片的识别色，歌词和符咒都用它。

## 4. 字与歌词

- 歌词写在**黄纸符**上：竖条黄纸，朱砂红的手写体（OFL 书法字体：Zhi Mang Xing / Liu Jian Mao Cao / Ma Shan Zheng），按拍点“啪”地贴上画面（有一点弹跳和纸的抖动），唱完时从一角开始烧掉。
- 副歌的标题词可以是大字：白纸黑字的冥币式印刷排版，或者一排符咒同时贴满画面。
- 画面里的招牌、票据、手机界面用纸扎店的手写和印刷混合风格，文字要能读。
- 字不能挡住纸人的脸。

## 5. 动作质量

- **纸偶的动**：身体几块纸板由几个关节连着，动作有停顿感，按两拍（12 fps）步进；关节处可以看到固定的小纸钉。
- **不动的脸**：头部可以转，脸永远不变。**回头**是这个风格最重要的动作：头沿着竹签转过来，身体不动。
- **只有纸边会软**：风吹时纸的边角飘动（每帧平滑），这是画面里唯一柔软的东西。
- 纸扎交通工具的轮子可以平滑地转（辐条是纸条），纸人的肢体是僵的。

## 6. 镜头语法

| 镜头 | 表达 | 可用于 |
|---|---|---|
| 横向跟拍 + 多层视差 | 夜游、一路经过 | 主歌、骑行 |
| 正面固定机位，纸人走进画面 | 仪式感、不对劲 | 便利店门口、电梯里 |
| 极近特写：画出来的眼睛和腮红 | 不变的表情 | 预副歌“回头” |
| 俯拍斑马线 | 布景感、棋盘感 | 开场、副歌 |
| 越过肩膀看后面（POV） | 不安、被注视 | 一句带警告意味的歌词 |
| 背光剪影 | 剥开外壳、露出真相 | 一句关于“真相”或“剥开”的歌词 |
| 拉远到整个纸扎店橱窗 | 这一切都是扎出来的 | 结尾的揭示 |

## 7. 转场

- **烧纸**是主转场：从画面某处点着，烧穿，露出下一个场景。用在段落之间。
- **纸片翻面**：前景一块纸板翻过去，背面是下一个场景。
- **灯笼摆过**：一只灯笼从镜头前摆过，扫过之后换场。
- 硬切用在节拍上的快剪（副歌）。不用普通的淡入淡出。

## 8. 与歌配合

- 主歌：横向跟拍的夜游，一句一个经过的纸扎物件。
- 预副歌：安静下来，镜头推近纸人的脸，最后一句时**回头**，停住一拍的沉默。
- 副歌：符咒随鼓贴满，快剪，物件按拍点出现。
- 最后一段副歌前的过门或吟唱：符咒飘走、烧掉，全片最亮的一次烧纸。
- 结尾：拉远，发现整个世界是纸扎店橱窗里的一个布景。

## 9. Native moves

- **烧纸转场**：纸被点着，火边推进，露出下一个世界。适合：段落转换、超度、告别。
- **回头**：纸人的头沿竹签转 180°，脸不变，时间停一拍。适合：一句让人背后发凉的话。
- **背光显骨**：光从纸后亮起，照出里面的竹篾骨架。适合：“剥开外壳”、真相。
- **影子自己动**：纸人的影子投在墙上，影子做了本体没做的事（皮影式剪影）。适合：影子做了本体不会做的事。
- **符咒贴满屏**：黄纸符按拍点一张张贴上来，直到画面被盖满。适合：副歌、咒语、刷屏。
- **橱窗揭示**：镜头拉远，一切原来是纸扎店里的布景。适合：结尾。

## 10. 常见坑

- 纸看起来像矢量图 → 必须有纤维噪声、折痕、边缘不齐、拼缝。
- 纸人太可爱 → 眼睛小而定、腮红正圆、比例偏僵（头略大，手臂是直的纸板），动作不要弹。
- 太吓人 → 不出现血、鬼脸、跳吓；诡异来自“安静”“不变”“一切都太正常了”。
- 全片太暗 → 每个镜头至少一个明确的光源，纸人的脸必须被照亮。
- 烧纸转场用太多 → 只在段落之间用，快剪部分用硬切。
- 字挡脸 → 符咒贴在纸人身边，不贴在脸上（除非是故意的一次）。

## 11. 引擎计划

- `paper.js`：纸面（纤维噪声缓存成贴图，用 pattern 填充）、折痕、边缘抖动、拼缝、背光透射与骨架。
- `puppet.js`：纸偶骨架（头、身、双臂、双腿，关节 + 关键帧 + 12 fps 步进），画脸函数，回头动作。
- `vehicle.js`：纸扎交通工具（自行车、汽车等），纸条辐条，灯笼挂在车上。
- `set.js`：布景层（斑马线、便利店、电梯、街道），视差相机。
- `burn.js`：WebGL 烧纸转场（噪声阈值 + 火边 + 灰烬），放在后期里作为两个镜头之间的混合方式。
- `talisman.js`：黄纸符歌词（贴上、抖动、烧掉）。

## 12. 变化空间

- 结构：**一夜的路线**（一路经过一串场景，有起点和终点）；**纸扎店的一夜**（橱窗里的纸扎在打烊后活过来）；**快递单**（每段是一个快递的物流节点）。
- 开场：**一盏纸灯笼被点亮**；**一张黄纸符被点燃**；**橱窗里的灯亮起**。
- 结尾：**橱窗揭示**；**纸人走进画面深处的一道光里**；**全部烧成灰，灰里剩一个小物件**。
