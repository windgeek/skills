# 水的光学 · Water Optics — Style Prompt

> 用 WebGL 着色器画光在水里、玻璃里的样子：折射、焦散、失焦光斑、水下仰望时看到的那一圈天光。画面像微距摄影，安静、湿润、克制，情绪靠光的颜色和水位来讲。
> 参照（只学语法）：静物摄影的浅景深；水下摄影里的斯涅尔窗和光束；夜里厨房、雨窗这种日常空间。

## 1. 它是什么，它不是什么

- **光学是主角**：玻璃边缘的高光、水里被折射翻转的背景、桌面上晃动的焦散、水面倒映的一根灯管。
- **微距与浅景深**：主体清楚，背景是一片失焦的光斑。
- **没有人，或者只有剪影和手**：情绪交给物件和光。
- **颜色就是情绪**：冷青的夜 → 琥珀色的桥段 → 金色的黎明。

它不是：卡通矢量画、粒子特效堆砌、写实的人物动画、赛博霓虹。

## 2. 招牌时刻

- **容器里的海**：一个日常容器里装着一整片海，天上悬着一个人造光源当月亮。适合：把一种很大的情绪装进一个很小的日常物件。
- **漫出来**：水漫过杯沿、流过桌面、滴到地板。适合：情绪溢出。
- **沉下去**：镜头沉到水下，往上看水面和光。适合：被淹没、副歌的最高点。
- **变暖**：同一片水从冷青慢慢变成琥珀色。适合：接纳、和解。
- **退潮**：水位一点点降回去，只剩一层。适合：结尾、留下一点东西。

## 3. 材质与渲染

- 一个片元着色器里放多个场景，用 `uScene` 选择；场景参数用 `uP0–uP3` 传。
- 玻璃：2.5D 近似。杯壁内侧的背景做水平翻转和放大（柱面透镜）；边缘加暗、再加两条细高光；水面是一个椭圆，上面有一条被波纹打碎的灯管倒影。
- 海面：高度场光线步进 + 二分细化，法线用有限差分；菲涅尔混合天空（灯管或黎明）和水体颜色；浪尖加一点白沫。
- 水下：光线和水面平面求交，用 `refract` 算折射；超过临界角就是全反射的暗色；体积光束用沿视线的多次噪声采样叠加；悬浮颗粒和气泡用屏幕空间的格子随机点。
- 焦散：扭曲后的 Voronoi 边缘，**一定要软、要有光池的衰减**，否则像裂纹和网格。
- 后期：HDR 帧缓冲，辉光用 mipmap 模糊（不要离散采样，会出条纹），轻微色差、暗角、色调映射。颗粒放到 ffmpeg 里加。

## 4. 色彩

- 夜：冷青、墨蓝，灯管是唯一的白。
- 桥段或转折：整片水的颜色走向琥珀，灯也跟着变暖。
- 黎明：粉橙的天、金色的光斑、灰尘在光里浮着。
- 全片只走一次“冷 → 暖 → 亮”的弧线，不要来回切。

## 5. 字与歌词

- 竖排的宋体或明朝体，放在画面一侧，逐字淡入；关键句居中大字，加柔和阴影。
- 字在水下时可以轻微折射晃动。
- 宽银幕黑边（2.39:1）让画面更像电影，字可以放在黑边里。

## 6. 动作

- 水面、光斑、灰尘一直在缓慢地动；镜头很慢地推、漂。
- 大的变化（水位、颜色）都是几十秒的缓慢过程，不是一下子跳过去。
- 快只出现在副歌：按拍点切换“容器里的海 / 杯子特写 / 水纹俯视”。

## 7. 镜头与转场

| 镜头 | 表达 | 用在哪里 |
|---|---|---|
| 灯管失焦特写 | 开场、深夜、不安 | 片头 |
| 杯子静物，慢推 | 克制、忍住 | 主歌 |
| 容器里的海，低机位看海面 | 情绪的真实大小 | 副歌第一拍 |
| 水纹俯视 | 声音、心跳、回响 | 对应歌词里的声音 |
| 雨窗、起雾的玻璃被擦开 | 看不清、慢慢看清 | 过渡 |
| 水下仰望 | 被淹没、放下 | 副歌二、桥段 |
| 晨光落在墙上、门缝的光 | 离开、新的一天 | 尾声 |

转场：硬切为主；段落之间用慢叠化（水的媒介适合溶解）。

## 8. 与歌配合

- 主歌：长镜头，一个镜头 5–10 秒。
- 预副歌：灯开始闪，镜头越推越近。
- 副歌第一拍：闪白，第一次看到“容器里的海”。
- 桥段：一个长镜头，水变暖。
- 最后一段副歌：退潮、天亮。
- 尾声：回到开头的物件，只留一层水。

## 9. 常见坑

- 焦散像网格、裂纹 → 软化边缘，加光池衰减，不要铺满全屏，出场不要太多次。
- 大面积细亮线被辉光采样成条纹 → mipmap 辉光。
- 页面里画颗粒 → 文件暴增，放到 ffmpeg。
- 亮背景上的白字看不见 → 加阴影。
- 窗格光斑像“视窗”标志 → 边缘要软，只留一根窗棂。
- 全片太暗 → 每个镜头都要有一个明确的光源。

## 10. 引擎计划

- `shaders.js`：场景着色器（灯管、玻璃杯、容器里的海、水下、雨窗、门缝、水纹、焦散/晨光）。
- `film.js`：全局状态（灯、水位、暖度、黎明）+ 剪辑表 + 歌词。
- 引擎的后期管线直接用。

## 11. 变化空间

- 结构：**一夜**（从深夜到黎明）；**一个物件的一生**（一杯水被倒满、打翻、蒸发）；**潮汐**（每段副歌一次涨潮）。
- 开场：灯被打开；一滴水落进杯子；雨窗上的一道擦痕。
- 结尾：只剩一层水；门打开，光进来；一片干了的水渍。
