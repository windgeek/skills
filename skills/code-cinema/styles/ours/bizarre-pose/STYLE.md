# 奇妙冒险 · 摆姿漫画 — Style Prompt

> 80–90 年代少年热血漫画中最“奇妙”的那一支，用代码重建：扭到极限的时装模特式站姿、密集的交叉排线阴影、漂浮在空中的巨大拟声字、每个镜头都可能突然换掉的色板、以及“静止的画格”和“连打的冲击帧”之间的剧烈对比。
> 参照（只学语法）：80–90 年代日本少年漫画的分格与排线；受时装插画和古典雕塑影响的人体姿态；电视动画改编里的任意换色、画格定格、冲击帧；意大利文艺复兴雕塑的扭转体态（contrapposto）。不画原作角色，不用原作的招牌道具（石头面具等）、口号、标志和结尾箭头；片中不出现原作的专有名词。

## 1. 它是什么，它不是什么

四样东西叠在一起才是这个风格：

- **姿态**：人物不是“站着”，而是摆出雕塑般的扭转：髋一边、肩一边、头再反一次，手指张开贴在脸侧或指向镜头。每个姿态都是一个定格。
- **排线**：阴影用密集的平行线和交叉线画，不用灰度渐变。越紧张，排线越密，最后整张脸只剩一半在阴影里。
- **拟声字**：巨大的、有厚度的片假名/汉字拟声（ゴ、ド、ズ、轰、咚）漂浮在画面里，带阴影和透视，本身就是画面主体。
- **换色**：同一个镜头，情绪一变，整个色板直接换掉（紫皮肤、绿天空、黄色背景），不讲道理。

它**不是**写实美式漫画（没有网点灰阶），不是现代干净的日系赛璐璐，不是 Q 版。不是“随便加点拟声字”：拟声字的位置、大小、节奏都要被设计。

## 2. 材质与渲染

- **线**：粗细变化大的墨线（压感笔触），外轮廓粗、内部细。用 Canvas 路径加宽度函数画，不是等宽描边。
- **排线**：阴影区域 clip 后填平行线，角度随光的方向；二级阴影再叠一层交叉线。排线密度 = 紧张程度，是一个可以随时间变化的参数。
- **高光**：少而硬，嘴唇、眼睛、金属各一处。
- **速度线 / 集中线**：背景被放射状的线条取代，中心对准人物的眼睛或拳头。
- **画格**：画面可以被切成倾斜的漫画格，人物的一部分冲出格子边界。
- **冲击帧**：一两帧的纯黑白反相或纯色剪影，用在打击点。
- **定格**：动作最高点整个画面冻结，变成一张单色（棕、紫、绿）的“书页”，有纸张质感。

## 3. 色彩逻辑

- 默认色板是**高饱和但不和谐**的组合：紫与黄、粉与青、绿与红。每个镜头一套，允许镜头间完全不连续。
- 人物的肤色可以是任何颜色，只要这个镜头的色板统一。
- 主角有**一个识别形状**（发型轮廓或一件配饰），不依赖颜色识别，因为颜色一直在换。
- 全片有一个核心意象（火、光、信物都可以），永远保持同一种金色，是唯一不随色板变的东西。

## 4. 字与歌词

- **拟声字**：粗黑体或粗明朝，有厚度（3D 挤出 + 阴影），轻微颤动，按拍点出现。可以是日文片假名或中文单字（轰、咚、铮）。自己设计组合，不照搬原作的标志性拟声组合。
- **歌词**：
  - 主歌：画格旁边的小字，竖排，像漫画的旁白框（白底黑字的方框）。
  - 副歌关键句：变成巨大的、带透视的“台词字”，和拟声字同一套语法，占据半个画面。
  - 日文歌词原文上屏，可选小号中文译文。
- **段落标题卡**：可以用“第 X 部”式的章节卡分段（原创设计）。

## 5. 动作质量

- **姿态定格 + 局部运动**：身体定住，只有头发、衣角、拟声字、背景速度线在动。这和代码很合拍，也是这个风格的正宗做法。
- 过渡姿态用关键帧 + 缓动，有预备 → 动作 → 余势；最后落定的姿态卡在拍点上。
- **连打**：拳头的残影一拍四下、六下，每一下一个冲击帧，配合鼓的 16 分音符。
- 按两拍（12 fps）步进人物，速度线和镜头每帧平滑。

## 6. 镜头语法

| 镜头 | 表达 | 可用于 |
|---|---|---|
| 仰拍 + 强透视，人物指向镜头 | 宣言、挑战 | 副歌第一句 |
| 眼睛极近特写，一半在阴影里 | 决心 | 预副歌 |
| 慢推 + 排线逐渐变密 | 压迫感升高 | 对手出现 |
| 背对背的两个人，冲出画格 | 并肩 | 关于“传承”的句子 |
| 快速变焦（zoom punch）到拳头 | 打击 | 鼓的重拍 |
| 画格连环：同一动作分成 3–4 格 | 时间被拉长 | 最关键的一秒 |
| 定格变成单色书页 | 这一刻被记住 | 段落结尾 |

## 7. 转场

- **画格切分**：画面裂成倾斜的格子，下一个场景从格子里出现。
- **换色硬切**：同一构图，色板突变，本身就是转场。
- **拟声字擦除**：一个巨大的拟声字从画面这头飞到那头，扫过的地方变成下一个场景。
- **定格翻页**：定格成单色书页，翻过去就是下一场。这是本风格的 native move 候选。

## 8. 与歌配合

- 前奏：拟声字随鼓一个个落下（ド…ド…ド），人物剪影逐渐显形。
- 主歌：画格和旁白框，姿态一句一换。
- 预副歌：排线变密，镜头推近，拟声字加速。
- 副歌第一拍：换色 + 仰拍指向 + 巨大的歌词台词字。
- 间奏/器乐：连打或对峙，冲击帧锁在鼓点上。
- 最后一次副歌：所有识别元素同时出现，金色的核心意象最亮。
- 结尾：一张定格的单色书页，停满 3–4 秒。

## 9. Native moves

- **姿态定格**：人物在拍点上“啪”地落进一个雕塑姿态，背景同时换色。适合：宣言。
- **拟声字作为画面主体**：整屏被一个巨大的字占据，人物从字的缝隙里走出来。适合：压迫感、对手登场。
- **连打冲击帧**：拳头、残影、黑白反相，跟 16 分音符。适合：器乐段、最高点。
- **定格成书页**：动作最高点冻结，褪成单色印刷，纸张质感，翻页。适合：段落结尾、结局。
- **两代人的背影**：前一代人的背影和下一代人的姿态重叠在同一格里。适合：关于传承、接力的歌词。

## 10. 常见坑

- 姿态画成普通站立 → 每个定格姿态至少三处扭转（髋、肩、头），手要有戏。
- 排线用灰度渐变代替 → 必须是真的线，而且密度有变化。
- 拟声字像贴纸 → 要有厚度、透视、阴影，并且和拍点同步出现。
- 换色太频繁变成乱闪 → 换色只在段落转折和情绪突变时发生，一段内保持一套色板。
- 代码画的人体僵硬 → 先做姿态测试表（6–8 个关键姿态，放大检查肩、肘、手），通过后再进镜头。尽量用局部特写（眼、手、拳、背影）减少全身动画。
- 原作元素混进来（标志性道具、招牌口号、角色发型和姿势）→ 全部原创，只保留语法。
- 汉字多的大字糊成一团 → 大字用粗明朝 + 细描边，厚重的黑体只用于片假名拟声字。
- 剪影每个部件单独发光像线框 → 先画到离屏再整体加辉光。

## 11. 引擎计划

- `ink.js`：变宽墨线、排线填充（可变密度与角度）、集中线/速度线。
- `rig.js`：2.5D 人体骨架，姿态库（关键帧 + 缓动），头部函数（正、侧、3/4 仰视）。
- `sfx-type.js`：3D 拟声字（挤出、阴影、颤动、按拍出现）。
- `panel.js`：画格切分、冲出格子、定格书页、翻页转场。
- `palette.js`：每个镜头的色板，以及“金色核心意象”这个唯一的常量。
- `post.js`：冲击帧反相、纸张质感、轻微印刷错位。颗粒放到 ffmpeg。

## 12. 变化空间

- 结构：**两代人**（前半段一个人，后半段接过火的另一个人，最后两人同格）；**一场对峙**（整首歌是一次对视和一次出拳）；**章节卡**（每段一个“第 X 章”，四章讲完一个人的一生）。
- 开场：**拟声字随鼓落下**；**一只手握紧拳头的极近特写**；**一个背影站在夕阳里，已经摆好了姿势**。
- 结尾：**定格书页，翻到空白的下一页**；**金色的信物传到下一只手里**；**两个人的背影，同一个姿态**。
