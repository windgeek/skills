# 明朝体末日 · 心象极简 — Style Prompt

> 90 年代中期电视动画的“末日心理剧”语法，用代码重建：黑底上压扁的粗明朝体字卡、长到不安的静止镜头、夏天的电线杆与蝉声、突然爆发的闪切蒙太奇、十字形的光、红色的海。安静和爆发之间没有过渡。
> 参照（只学语法）：90 年代中期日本机器人动画中的心理剧段落和片头（字卡排版、静止长镜头、闪切、分镜稿与线稿直接上屏、实拍插入）；小津式的固定机位；瑞士排版的网格与不对称。不画原作的角色、机体、组织标志、界面设计，不用原作字体，片中不出现原作的专有名词。

## 1. 它是什么，它不是什么

三种状态，靠它们之间的**硬切**产生张力：

- **静**：固定机位、几乎不动的画面，一个很小的人物在很大的空间里（电线杆、十字路口、空教室、水面、天花板）。只有光、风、云、水在动。可以停 8–15 秒。
- **字**：纯黑底、白色（或警告红）粗明朝体，字号悬殊、换行不按语法，L 形排版，一个问题占满一屏。
- **爆**：0.08–0.3 秒一张的闪切，线稿、红色单帧、字卡、局部特写、噪点、倒转的负片，快到只能留下印象。

它**不是**赛博朋克霓虹，不是机甲战斗动作片，不是可爱画风，也不是满屏 HUD 的科幻界面。战斗和机器只以**局部、剪影和尺度**出现：一只巨大的手在地平线上，而不是全身帅气站姿。

## 2. 材质与渲染

- **赛璐璐平涂**：人物和物体是平涂加一层硬边阴影，线条细，偏暖深棕，不用纯黑。
- **背景是手绘水彩感的平面**：天空大块渐变，云有明确的受光面。夏天的午后是主场景。
- **电线和电线杆**：细黑线，把天空分割成网格。这是本风格的签名构图元素之一。
- **实物感插入**：纸质分镜稿（铅笔线、格子、手写时间码）、胶片划痕、老电视噪点，偶尔一帧，打断“这是动画”的幻觉。
- **光**：十字形的光柱（竖长横短）、从地平线升起的巨大光十字、水面反射的碎光。辉光强，色偏橙红。
- 画幅 16:9，不加宽银幕黑边（黑边留给字卡用的纯黑）。

## 3. 色彩逻辑

- 三套色板，一个场景只用一套：
  - **夏**：钴蓝天、白积云、电线黑、柏油灰、蝉鸣般的高饱和绿。
  - **警**：黑、橙红（#E8471F 附近）、白，界面和字卡用。
  - **海**：暗红到橙的液态海、紫灰天、苍白的月。
- 主角有**一个识别色**（原创的，比如一种发色 + 一件固定的衣服或配饰），在所有色板里都保持。
- 负片与单色：情绪崩溃时整个画面反相或降为单色红，只持续几帧。

## 4. 字与歌词

- 字体：压扁的超粗明朝体。**不用原作字体**（它是商业字体），用 OFL 的 Shippori Mincho B1 ExtraBold / Zen Old Mincho Black，水平压缩到 75–85%，字距收紧到负值。
- 版式：
  - **字卡**：黑底，一句话拆成 2–4 个字号（最大的字可以占屏高一半），左对齐或 L 形折转，留大片空白。
  - **歌词**：主歌用画面内小字（白字、右下或左上，竖排或横排统一一种），副歌关键句升级成整屏字卡。
  - **闪切字**：蒙太奇里一帧一个词。
- 日文歌词可以原文上屏，下面配一行小号中文译文（可选）。

## 5. 动作质量

- 极度省略的动画：人物大部分时间不动，只有头发、衣角、眨眼。“不动”要比“动”更有分量。
- 需要动的时候按两拍（12 fps）步进，镜头和光保持每帧平滑。
- 停顿是表演：一句话说完之后人物还停在原地 2 秒。

## 6. 镜头语法

| 镜头 | 表达 | 可用于 |
|---|---|---|
| 固定机位长镜头，人物很小 | 孤独、被世界忽视 | 主歌、开场 |
| 仰拍电线杆和天空 | 夏天的停滞、时间不走 | 段落之间的“呼吸” |
| 脸部极近特写，只露眼睛 | 内心被逼到墙角 | 预副歌 |
| 两人背对背 / 隔着门的对称构图 | 距离 | 关于“你”的句子 |
| 从极近的局部拉到极远的尺度 | 渺小和巨大 | 副歌第一拍 |
| 闪切蒙太奇 | 心理崩溃、记忆涌入 | 桥段或最后一次副歌前 |
| 空镜：水面、天花板、列车车厢 | 余韵 | 尾声 |

## 7. 转场

- **硬切**是主语法：从静止直接切进字卡，从字卡直接切进爆发。
- **字卡作为转场**：画面 → 纯黑字卡（问题）→ 下一个场景（回答或不回答）。
- **白闪**：一帧白，用在副歌第一拍和十字光出现时。
- **线稿退化**：画面一层层剥掉颜色，退回线稿、再退回分镜草图，用在“崩解”的时刻。这是本风格的 native move 候选。
- 不用柔和的叠化。

## 8. 与歌配合

- 主歌：长镜头，一段主歌 2–4 个镜头。
- 预副歌：镜头越来越近，字卡开始插入。
- 副歌第一拍：白闪 + 尺度揭示或十字光。
- 桥段：闪切蒙太奇，跟着鼓点每拍甚至每半拍一张。
- 尾声：回到开场的构图，但有一样东西变了（天色、人物转过身、多了一个人）。
- 至少一次**音乐还在响但画面完全静止**的长镜头，至少一次**画面爆发而歌词正好停住**的瞬间。

## 9. Native moves

- **一个问题的字卡**，在最高点前完全压住画面。适合：自我怀疑的歌词、“你是谁”。
- **尺度揭示**：从一只手、一张脸拉开，地平线上出现巨大的剪影或光十字。适合：副歌第一拍。
- **线稿退化**：彩色 → 线稿 → 分镜草图 → 白纸。适合：“溶化”“边界消失”。
- **红色的海**：世界被一种液体填满，所有人的形状溶开。适合：结尾前的高潮。
- **同一个构图的两次出现**：开场和结尾同一个电线杆镜头，只有一处不同。

## 10. 常见坑

- 字卡字体用成普通宋体 → 必须是压扁的超粗明朝，字距收紧，字号悬殊。
- 静止镜头太短，像是卡住了而不是“故意不动” → 至少 4 秒，并且有一个很小的持续运动（云、电线晃、光斑）。
- 闪切太长，变成了普通剪辑 → 每张 ≤ 0.3 s，一次爆发 2–5 秒就收。
- 人物画成现代日系萌系大眼 → 90 年代的比例：脸偏长，眼睛不超过脸宽三分之一，线条细。
- 橙红警告色用太多，失去冲击 → 全片只在两三个时刻出现。
- 原作元素混进来（组织标志、机体轮廓、界面图形）→ 全部原创，只保留语法。

## 11. 引擎计划

- `bg.js`：夏日天空、积云、电线杆与电线网格、十字路口；每个背景画一次，缓存，只做平移。
- `cel.js`：平涂 + 硬边阴影的人物绘制，头部函数统一（正、侧、3/4）。
- `card.js`：字卡排版引擎（字号分级、L 形折转、压扁、闪切模式）。
- `fx.js`：十字光、红色的海（WebGL）、线稿退化（边缘检测 + 逐层剥色）、负片、噪点。
- `post.js`：辉光（mipmap）、色偏、轻微胶片划痕。颗粒放到 ffmpeg。

## 12. 变化空间

- 结构：**一天**（从清晨到黄昏的同一个路口）；**一场对话**（两个人隔着一扇门，只有字卡说话）；**倒计时**（字卡上的数字从副歌开始倒数）。
- 开场：**一个问题的字卡**；**天花板的特写**（醒来）；**已经在进行中的蝉鸣和电线杆**。
- 结尾：**同一构图，多了一个人**；**画面退回分镜草图，最后一格是空的**；**红色的海边，一个人站起来**。
