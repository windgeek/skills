# 按内容选择呈现方式

风格不是皮肤，是这支片子“用什么材料说话”。用错了媒介，再好的画面也只是装饰。

## 1. 四个问题

1. **媒介能不能就是内容？**（最重要）
   题材里本来就有一种物质、工艺或媒介时，就用它来画：
   - 雨夜的玻璃窗 → 水的光学（折射、焦散、水下）。
   - 纸人 → 纸扎，转场就是烧纸；现实里人们真的会烧纸扎的手机和汽车，荒诞就在这里。
   - 宣言、传承、热血 → 漫画：拟声字、换色、定格成书页。
   这样选出来的风格，自带“只有它做得到”的招牌时刻。
2. **文化语境是什么？** 中式民俗、日式夏天、互联网当代……两种语境撞在一起时（民俗 × 现代生活），撞击本身就是看点，风格要能同时装下两边。
3. **情绪和能量曲线？** 内省、安静 → 留白多、长镜头的风格；热血、宣言 → 强对比、强节奏；荒诞 → 一本正经的形式装荒诞的内容。
4. **代码能不能画到高水准？** 代码最难画的是全身人物表演。需要角色的内容，优先选能用剪影、局部特写、定格、纸偶关节来表达的风格；先做测试。

## 2. 自带的风格

见 `styles/INDEX.md`。先在这四个里找；贴合就用，只贴合一半就混合或改写，不贴合就原创。

## 3. 可以原创的方向（尚未写成规格）

这些是判断“代码能做好、而且有内容适合”的方向。遇到合适的歌，按 `style-template.md` 写成新的规格，做完登记进 INDEX：

| 内容特征 | 可以考虑的媒介方向 | 为什么 |
|---|---|---|
| 回忆、旧时光、家 | 褪色胶片、老照片、录像带 | 媒介本身就会“旧”：划痕、跳帧、色偏 |
| 游戏人生、打工、重复 | 像素、关卡、存档画面 | 日常被游戏化，荒诞自己出来 |
| 数字生活、AI、信息过载 | 终端字符、界面、弹窗 | 界面就是这种生活本身 |
| 诗意、古典、留白 | 墨在宣纸上晕开 | 墨会扩散、会干，天然的转场 |
| 童年、温柔 | 蜡笔、纸片立体书 | 手工的不完美就是温度 |
| 仪式、史诗 | 光穿过彩色玻璃、版画 | 光和刻痕都有庄严感 |
| 城市夜晚、青春 | 霓虹、雨夜反光、赛璐璐 | 背光和湿地面天然有情绪 |

## 4. 混合的规则

- **一主一辅**：主风格占 70% 以上；辅风格只在一个段落出现，而且它的出现本身是一个事件（例：纸扎风格里，“影子自己动”借一次皮影的语法）。
- 两种风格之间的切换要有媒介内部的理由（纸被烧穿露出后面的东西、画面定格成书页）。
- 不要三种以上，不要每段换一种风格来“展示能力”。
