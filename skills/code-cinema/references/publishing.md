# 发布：B 站与抖音

从两次发布准备里总结的做法。每支片子各写一份 `发布文案.md`（B 站）和 `抖音文案.md`。

## 顺序
B 站首发（横版完整 MV）→ 1–2 天后抖音（竖版切片）。

## 封面
- **B 站**：16:9，另裁一张 4:3（首页推荐位），关键内容放在中间 4:3 里。
- **抖音**：9:16，另裁一张 3:4（个人主页网格），关键内容放在中间 3:4（y 240–1680）。
- 取画面时关掉字层（`FILM.drawText = () => true`），再把大字重新排上去，不要让原来的歌词混进封面。
- 封面的大字和标题不要重复同一句话。
- 最好的封面往往是全片最有辨识度的那个意象：一张正脸 + 一句歌里的反问；一个道具特写 + 一句钩子；一双眼 + 一个拟声大字。

## B 站文案
- 分区：音乐区 → 原创音乐。
- **标题**：三个备选，用歌里最反常识、最有画面的一句当钩子，“｜”后接歌名。
- **简介**：三句话讲歌 → 一句话讲 MV 怎么做的 → 章节时间戳（按剪辑表合成 12–16 段）→ 听完整音源的方式 → 署名。
- **站外链接**（音乐平台等）放在置顶评论或动态里，简介里只写“在 XX 平台搜索……”。
- **标签**：10 个。
- **置顶评论**：一个能让人回答的问题（“你觉得歌里那个世界，下一个会出现什么？”）。

## 抖音文案
- **标题**（作品标题栏）：一句钩子。
- **正文**：两三句 + 一个互动问题 + 署名和平台搜索提示 + **正好 5 个标签**。
- 不写 B 站、不放外链（容易限流）；视频结尾引导到完整音源所在的平台。
- 发布页能关联音乐平台上的原曲就关联。

## 竖版
- `vertical.html` + `vertical.js`：横版画面放中间，背景是同一帧放大模糊，顶部两行钩子，画面下方大字歌词，底部 28% 留给平台界面，最后两三秒引导到完整音源。
- **默认做完整版**：竖版和横版内容一致（`from: 0, to: 片长`，字幕用全部歌词），只是换成 9:16 排版。
- 只有用户明确要“高潮版 / 切片 / 精华版”时才剪一段：选 40–60 秒，用最强的钩子开头（最有冲击力的一个动作；连打 → 最终副歌），不要从安静的前奏开始。做了切片要在交付时说清楚是片段。
- `node render.mjs --page vertical.html --name <片名>_抖音竖版`。

## 署名
- 片头一行小字 + 片尾署名卡（歌名、词曲、各平台账号）。视频被转载时，署名还在画面里。
- 署名写法以用户为准，开工前问一次。

## 每次都要提醒
- **AI 生成内容声明**：B 站“创作声明”、抖音“高级设置 → 作者声明”。
- 用户不想写“XX 风 / 致敬”时只写“原创”；画面里不出现原作角色、标志、原片素材。
- 搜索标签里要不要保留相关作品名，让用户决定。
