# 一杯水放凉，需要多久

> 热水不会一下子变凉。它先把最烫的那一层交出去，剩下的，慢慢来。

早上七点四十，我倒了一杯开水，放在键盘左边，然后开了一个会。会开到八点二十，水温刚好能喝。这四十分钟里，那杯水做了很多事，只是没人看它。

**牛顿冷却定律**说的是：物体降温的速度，和它与环境的温差成正比。温差越大，凉得越快；越接近室温，越磨蹭。

## 头十分钟最快

一杯 90 ℃ 的水放在 25 ℃ 的房间里，温差是 65 ℃。这时候它每分钟能降两三度。等到 50 ℃，温差只剩一半，降温也慢了一半。

所以“晾一会儿”这件事，==前面的五分钟比后面的二十分钟管用==。

## 三个能动手的办法

1. 换一个敞口更大的杯子，让水面多晒一会儿空气。
2. 往杯口吹气。吹走的是水面那层湿热空气，蒸发会快一点。
3. 倒进另一个凉杯子里，再倒回来。杯壁会吸走一部分热量。

- **不推荐**：放进冰箱。省下的时间不多，冰箱却要多干活。
- **可以试**：搅拌。它让底部的热水上来，表面一直保持在最热的状态。

### 一段算温度的代码

```python
import math

def temp(t, start=90, room=25, k=0.03):
    """t 分钟后的水温"""
    return room + (start - room) * math.exp(-k * t)

print(round(temp(40), 1))  # 约 44.6
```

| 时间 | 水温 | 能不能喝 |
|---|---:|:---:|
| 0 分钟 | 90 ℃ | 不能 |
| 10 分钟 | 73 ℃ | 小口 |
| 40 分钟 | 45 ℃ | 能 |

---

> 你等的不是水变凉，是它和房间慢慢谈妥。

`k` 这个系数取决于杯子：陶瓷杯小一些，薄玻璃杯大一些。想知道自己那只杯子的 `k`，量两次温度就能算出来，具体做法见[这份讲义](https://example.com/cooling)。
