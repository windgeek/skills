# 公众号排版 · 书页

排版只做一件事：让文章读起来像书里的一页。读者该注意到的是字，不是装饰。

三条底线，任何时候都不破：

- **正文是主角。** 不用卡片、图标、渐变、底色块、表情、花边分割线。
- **全篇只有一种颜色。** 朱砂 `#9a3b26`，只出现在章节短线或编号、列表符号、高亮底纹、注释角标、文末小方块这几处。
- **原文一个字不改。** 不加题记、金句、作者名、关注引导、图片说明、“点赞在看”。原文有就排，没有就没有。

样式由脚本确定性生成，不手写 HTML，也不照着模板拼。这样同一份母稿永远排出同一个样子，原文也不会在拼装时被改写。

## 流程

1. **拿到母稿。** 通常是 wechat-article 产出的 `*-gzh.md`。其它格式先转成 Markdown（docx 可用 `textutil -convert txt` 或 pandoc，PDF 先提取文字），转完通读一遍确认没丢段落。没有内容就向用户要，不虚构。
2. **决定要不要章节编号。** 教程、清单、步骤型、章节彼此并列的文章加 `--numbers`（标题上方出现朱砂色 01、02）；随笔、叙事、观点文不加，用一道朱砂短线代替。原标题已经带“一、”“1.”的不会重复编号。
3. **排版：**
   ```bash
   python3 <本skill目录>/scripts/typeset.py 母稿.md [--numbers]
   ```
   输出在母稿旁边：`<母稿名>-排版.html`。报告里的 WARNING（一段加粗超过 2 处、高亮超过 3 处等）要处理：**改母稿再重排，不改 HTML**，删强调前先问自己哪一处最承重。
4. **校验：**
   ```bash
   python3 <本skill目录>/scripts/check_html.py 母稿-排版.html
   ```
   ERROR 和 WARNING 都修到 0。中文旁边的半角标点、直引号同样改母稿。
5. **预览：**
   ```bash
   python3 <本skill目录>/scripts/preview.py 母稿-排版.html
   ```
   打开 `<母稿名>-预览.html` 从头看到尾：首屏、每个章节标题、图、表、代码、结尾；再点“深色”看一遍（模拟微信深色模式的自动反色）。
6. **交付：** 给出排版 HTML 和预览页的路径、公众号标题（报告里那一行，发布时填进标题栏，正文里默认不重复排标题）、校验结果，以及用法：打开预览页 → 点“复制正文” → 到公众号编辑器粘贴。发布走 wechat-article 的发布流程，用户明确说“发布”才发。

## Markdown 对照

| 母稿写法 | 排出来的样子 |
|---|---|
| `# 标题` | 不进正文（公众号自带标题栏）；要排进正文用 `--keep-title` |
| 正文前的 `> 引言` | 题记：居中、小一号、灰，下面一道短线 |
| 正文中的 `> 引用` | 左侧一道浅线，灰字 |
| `## 章节` | 朱砂短线（或 `--numbers` 时的 01）+ 加粗标题，上方大段留白 |
| `## 信息来源` / `参考资料` / `免责声明` 等 | 小字区：细线隔开，13px 灰字，链接后直接附网址 |
| `### 小节` | 加粗，不加颜色 |
| `**加粗**` | 加深加粗，不变色 |
| `==高亮==` | 朱砂淡底纹，全篇最多 3 处 |
| `*强调*` | 朱砂色字，少用 |
| `<u>下划线</u>` / `++下划线++` | 朱砂细下划线 |
| `` `代码` `` / 围栏代码 | 纸色底、等宽字；长行可横向滑动 |
| `[文字](网址)` | 文字后加角标 [n]，网址列在正文之后（公众号正文外链点不开） |
| `![说明](图片)` | 居中图片，非空的说明排在图下作图注 |
| 列表、表格 | 朱砂列表符号；表格细线、表头纸色底，支持对齐 |
| `---` | 居中 `· · ·`；紧挨在章节标题前的 `---` 自动省略 |

正文最后一段末尾会跟一个朱砂小方块作为文末记号，不要时加 `--no-endmark`。

## 改样式

样式写在 `scripts/typeset.py` 顶部的常量里，每个取值的理由见 [references/style.md](references/style.md)。

- 只在用户要求时改，不为单篇文章临时换风格。`--accent` 只在用户指定颜色时用。
- 改完用 [assets/sample.md](assets/sample.md)（覆盖全部写法）和最近一篇真实稿件重排，浅色、深色各看一遍，再交付。

## 平台约束

公众号编辑器会过滤 `<style>`、`<script>`、`class`、`id`、`<div>`、定位、浮动、grid、CSS 变量和 @ 规则；h1–h6、ul/ol 会被套上编辑器自带样式。所以脚本只输出 `<section>`、`<p>`、`<span>`、`<strong>`、`<img>`、`<table>` 加内联样式，每段文字包在 `<span leaf="">` 里。`check_html.py` 会把这些逐条查一遍。
