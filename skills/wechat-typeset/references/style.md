# 书页：设计说明

改样式之前先读这一页。每个取值都有理由；改一个值，先想清楚它原来在解决什么问题。

## 总的想法

参照物是一本排得好的中文书，而不是一张海报。公众号读者在手机上、在通勤里读，干扰已经够多了，排版不再增加干扰：

- **字是主角。** 没有卡片、底色块、图标、渐变和阴影。层级只靠字号、字重、灰度和留白。
- **一种颜色。** 默认朱砂 `#9a3b26`，取自印章和批注的颜色，是一种“有人读过、圈过”的颜色，而不是“请注意”的颜色。按文章内容可以换成别的沉稳颜色，与封面协调，但全篇只用一种。它只出现在结构记号上（编号、列表符号、角标、文末方块）和极少的高亮里，从不用于大段文字。
- **宋体。** 书的正文和章首都是宋体。正文、标题用宋体（iPhone 的宋体，安卓有思源宋体就用，没有就退回系统字体），代码仍用等宽字体。
- **留白比装饰重要。** 章节标题上方留近三行空，比加一条横幅更能让人知道“换了一件事”。
- **不替作者说话。** 排版不添加任何原文没有的字。题记、图注、来源都来自原文。

## 取值

| 元素 | 取值 | 理由 |
|---|---|---|
| 正文 | 宋体 16px，行高 1.9，字距 0.05em，段距 1.35em | 手机上 16px 是不费力的下限；1.9 的行高让中文长段不压抑；段距大于行距，段落一眼可分 |
| 正文颜色 | `#2b2b2b` | 纯黑在白底上偏硬，长读刺眼 |
| 对齐 | 纯中文两端对齐；英文字母超过 8% 改左对齐 | 两端对齐让中文行尾整齐，但会把英文单词间距拉开 |
| 加粗 | 600、`#111` | 只加深不变色；颜色留给结构 |
| 章节标题 | 宋体 20px、700，居中，字距 0.16em，上留 3.2em；不加短线 | 书的章首就是居中的一行字加留白。左对齐的加粗黑体配一道短线像博客，不像书 |
| 编号（`--numbers`） | 13px 等宽、点缀色、居中、字距 0.18em：01 02 | 像书的章节号，不像 PPT 的大圆圈 |
| 小节标题 | 16px、600，无颜色 | 比正文只高一级，不抢章节标题 |
| 题记 | 15px、`#5c5c5c`、居中，下方 28px 细线 | 题记是作者递给读者的一句话，轻声说 |
| 引用 | 15px 灰字，左侧 2px 浅线 `#e7e3db` | 能看出是别人的话，但不跳出页面 |
| 高亮 | 字下 40% 高度的朱砂 16% 底纹 | 像用荧光笔轻轻划过；全篇最多 3 处，多了就不是重点 |
| 代码 | 12.5px 等宽，纸色底 `#f6f4ef`，不折行 | 代码要原样，横向滑动好过错误折行；不做终端窗口的三个圆点 |
| 表格 | 14px，只有横线，表头纸色底 | 竖线会把手机屏切碎 |
| 图片 | 居中、不强制拉伸，图注 13px 灰 | 小图拉满会糊 |
| 分隔 `---` | 居中 `· · ·`，`#a8a39a` | 书里换场景常用的空行加星点 |
| 链接 | 角标 [n]，网址列在正文之后 | 公众号正文外链点不开，写进正文又打断阅读 |
| 来源、免责 | 13px 灰，细线隔开 | 需要时能找到，平时不打扰 |
| 文末记号 | 6px 朱砂方块，跟在最后一段之后 | 杂志的收尾记号：读到这里就完了，不需要“END”或“点个在看” |

## 深色模式

微信深色模式会自动反转浅色背景和深色文字。所以：

- 不用大面积底色块（反色后变成突兀的黑块），纸色只用于代码和表头。
- 灰度不要太浅，浅于 `#b0b0b0` 的字在深色下几乎看不见。
- 每次改颜色，都在预览页切“深色”看一遍。
